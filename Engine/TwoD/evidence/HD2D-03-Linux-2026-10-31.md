## Implemented contract

The shared shader evaluates flat ambient/point illumination, smooth bounded distance attenuation,
linear color/intensity and receiving/group masks. Decorative strength applies once to point lights.
The CPU validates all render values before radius/frame culling and freezes the rotated camera
inverse with safe-frame offsets. The Player publishes copied effects before updates, resolves live
entity/pool identities after updates and carries value styles through common Sprite/tile sorting.
Only adjacent Atlas/style matches batch. Null/disabled effects retain the existing rendering path;
HUD remains outside lighting/tone mapping. Original geometry/batch budgets still apply to style
splits; configured-override capacity is not a draw-count or FPS guarantee.

The optional `pool_identity` table tail validates the complete existing owner/index/generation
handle and allocates a bounded service-local opaque identity. No truncation/hash of the 128-bit
pool handle, no sorted-index association and no persistent pointer is used. The original effects
prefix negotiates independently with both old/new hosts and modules. The stable Sprite wire and
outer services prefix remain unchanged. Registry retirement does not retain World/instance owners.
