# Scoped graphical semantic source inspection — Linux cloud evidence

The actual native Editor transfers generation-bound compare/cancel requests from its File menu,
Ctrl+Alt+D and external-save conflict modal. Its application owner captures saved baseline and
prepared local revisions, then an owning cancellable job reads bounded disk bytes and invokes the
accepted semantic parser in isolated Worlds. Workers borrow no workspace/document and write no
source. Shutdown joins before document lifetimes end. Ready is an immutable captured disk snapshot,
not overwrite authority; the existing Replace confirmation still rechecks actual disk revisions.

The table shows stable entity/field paths and optional Base/Local/Disk values, distinguishing
absence from empty text. Unresolved fields and local/remote/shared hints are inspection only.
Clipped rows, bounded UTF-8-safe previews/tooltips and validated owning observations retain the
SDK's source/entity/value/result budgets. Rejected observations have no partial result. Scope
changes clear retained results and queued controls. Compare never applies a hint or edits history,
selection, dirty baselines or sources. Read-only/reference sessions use const file access.

## Actual acceptance

The background-owner fixture uses real files/documents and the actual Core worker. It verifies
three-revision conflicts and unchanged history/baselines; busy rejection, deterministic queued
cancellation, changed local content, replaced document generations, advanced saved baselines,
and a distinct file-session identity with the same token/path all reject old publication. Corrupt
and oversized disk bytes fail without source changes; source deletion is an inspectable absent
revision. Shutdown drains and rejects new intake. A real additive reference denies writable
access yet produces an unchanged owning comparison through its const file session.

Real ImGui 1x/2x controls exercise File/menu/shortcut requests, overwrite-modal comparison, return
to the retained replacement decision, Cancel, read-only publication and malformed/over-budget
observations. Token/path changes clear stale results and requests. No UI fixture writes source.

The real X11 writer edits an unsaved document while an external edit changes the disk root.
Inspection reports actual changed fields without writing either version, then independent Undo
still works. A read-only relaunch yields an unchanged zero-row comparison; corrupt disk fails
and leaves its bytes untouched. The additive-tabs driver additionally compares from its actual
active reference and observes zero changed fields/conflicts while source authoring remains denied.
Existing native controls, aggregate Save All, reopen and corrupt composition tests remain intact.
The drivers reject native Vulkan validation/synchronization errors.
